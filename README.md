# Student Management System

## GTU PBL-3 – Python for Data Science

A Python-based Student Management System developed as a GTU PBL-3 project.

## Features

- Add student records
- View student records
- Search students by ID or name
- Update student information
- Delete student records
- Input validation
- Duplicate Student ID checking
- Delete confirmation
- CSV file storage
- Secure email encryption

## Beyond-Syllabus Implementation

The project implements **Fernet Symmetric Encryption** using Python's `cryptography` library.

Student email addresses are encrypted before being stored in the CSV file and decrypted when displayed in the application.

### Encryption Flow

Student Email  
↓  
Fernet Encryption  
↓  
Encrypted Data  
↓  
students.csv  

When displayed:

Encrypted Data  
↓  
Fernet Decryption  
↓  
Original Email

## Technologies Used

- Python
- Tkinter
- CSV
- Cryptography
- Fernet Symmetric Encryption

## Files

- `main.py` – Main application source code
- `students.csv` – Local student data file generated by the application
